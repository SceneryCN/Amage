# ChatPane

右侧对话面板。负责展示当前会话、发送消息、停止生成，以及预览图片。

## 数据流

`useChat` 订阅 `chat` 事件，并按会话 id 丢弃过期的加载结果。输入框保持非受控，只在发送时读取文本。附件用本地对象 URL 预览，发送时再转成 base64 交给后端。图片只在输入框内松开才会附上；落在其他位置会被拦住，避免 WebView 把图片打开成整页。

生成中的状态来自消息的 `streaming` 状态。还没收到文字时显示等待指示。文字增量按帧合并后再画到界面上，正文按 Markdown 渲染。打开一条会话或发送消息时列表停在最底部。生成过程中用户一往上滚动就停止跟随，滚回底部后才继续跟随。停止会取消这一条会话的生成，失败或取消后可以重试，不会再插一条用户消息。

## 边界

- 没有服务地址、密钥或对话模型时，发送按钮不可用，并说明原因。
- 生成图悬停后可以预览或另存。预览是全屏的，可以缩放、旋转、拖移和切换，Esc 先关闭预览。桌面端另存会打开系统保存框。
- 流式增量只追加到界面自己的消息副本，避免和存储对象共享引用。
